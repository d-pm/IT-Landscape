# IT Landscape

Project repository voor het vak IT Landscape — Graduaat Programmeren 2025-2026.

## Inhoud

- `app/` — Eenvoudige webapplicatie
- `Dockerfile` — Docker image definitie
- `.github/workflows/` — GitHub Actions CI/CD pipeline

## CI/CD

Bij elke push naar `main` wordt automatisch een Docker image gebouwd en gepubliceerd naar GitHub Packages via GitHub Actions.
